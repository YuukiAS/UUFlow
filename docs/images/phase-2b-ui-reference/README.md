# Phase 2B 界面参考

这些截图记录 2026-11-27 的 UUFlow 2.7.4 界面，用于 Phase 2B 决定 `windows / mac / off` 键盘状态放在哪里。

- `settings-screens-idle.png`：设置页的屏幕与连接状态区域；
- `settings-touch.png`：设置页的触控区域；
- `settings-general.png`：设置页的通用与权限区域；
- `menu-status-remote.png`：菜单栏的远程状态摘要；
- `about.png`：About 的产品身份与许可信息。

截图由已安装的 `/Applications/UUFlow.app` 使用仓库现有 `--render-*` 模式生成。渲染使用不含个人信息的样例状态，不会建立虚拟屏、读取远程会话或改动用户配置。

这些图片只记录 2B 开始前的界面基线，不表示键盘状态 UI 已经实现。
